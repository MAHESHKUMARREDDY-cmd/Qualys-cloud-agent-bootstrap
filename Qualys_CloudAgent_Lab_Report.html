1. Objective

Install the Qualys Cloud Agent on a Windows endpoint and verify successful communication with the Qualys Enterprise TruRisk Platform. This lab establishes the foundation for agent-based vulnerability management and continuous asset monitoring.

2. Concepts Learned

  • Cloud Agent architecture and agent-to-platform communication model
  • Activation Key creation and module provisioning (VM, SCA, PM, EDR, SwCA, MTG, ISL)
  • Agent installation via command-line with Customer ID, Activation ID, and WebServiceUri
  • Asset synchronization, inventory scan completion, and endpoint visibility in the portal
  • Windows service verification using sc query

3. Step-by-Step Procedure with Evidence

Step 1 – Login to Qualys Platform

Logged into the Qualys Enterprise TruRisk Platform at qualysguard.qg1.apps.qualys.in using VMDR trial credentials (username: ramk8rr). The portal confirmed a 27-day active trial.

sc query QualysAgent

5. Observations & Notes

  • The first activation key worked correctly — the agent installed successfully and reported to the platform within one hour.
  • The second install attempt (Student-Lab-key) failed because the Qualys agent was already present. To switch keys, uninstall the agent first or re-activate via portal Actions menu.
  • Asset location showed 'Location unknown' due to the private RFC 1918 IP range (192.168.x.x) having no geolocation data.
  • Only CSAM appeared in Agent Modules in the portal — other modules (VM, SCA, PM) may require a Configuration Profile update to activate scanning.
  • The Inventory Scan completed within approximately one hour, demonstrating the agent's near-real-time asset reporting capability.

6. Conclusion

The Qualys Cloud Agent was successfully deployed on the Windows 11 endpoint DESKTOP-FLSEJQ2. The agent established HTTPS communication with the Qualys Enterprise TruRisk Platform (QG1), completed an initial inventory scan, and appeared correctly in the Agent Management console with full asset metadata. This lab demonstrated the complete lifecycle: activation key generation, module provisioning, agent installation via CLI, and asset visibility confirmation in the portal.
